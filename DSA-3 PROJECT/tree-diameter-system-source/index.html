The idea, step by step

Why two passes of thinking are enough

A tree has no cycles, so every pair of vertices has one unique path. That structure lets a bottom-up recurrence find the global longest path in linear time.

01

Adjacency list

Store each vertex’s neighbors for compact O(N) space on a tree.

02

Depth-first search

Root the tree and record parents and traversal order without recursion.

03

Tree dynamic programming

At each vertex, retain the two tallest child branches. Their sum is a path through that vertex.

04

Diameter

Compare every through-vertex candidate; the longest is the tree’s diameter in edges.

05

Path reconstruction

Remember the branch endpoints and use parent links to join them through their common ancestor.

06

Linear-time guarantee

Each node and edge is visited only a constant number of times: O(N) time and O(N) space.
