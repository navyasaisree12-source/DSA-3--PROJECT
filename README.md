Tree Diameter Computation System
Overview

A Java Swing application that calculates and visualizes the diameter of a tree using DFS and Dynamic Programming.

Features
Create and validate a tree
Calculate tree diameter
Display the diameter path
Highlight the path visually
Demonstrate advanced algorithm concepts
Algorithms Used
Tree Dynamic Programming
DFS
KMP String Matching
Edmonds-Karp Max Flow
Vertex Cover Approximation
Randomized Quicksort
Complexity

Time: O(N)
Space: O(N)

Technologies

Java, Java Swing, Data Structures & Algorithms
